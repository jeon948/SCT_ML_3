# Cats vs Dogs Classification using SVM

This project is a Machine Learning model built using Support Vector Machine (SVM) to classify images of cats and dogs.

## Technologies Used

* Python
* NumPy
* OpenCV
* Scikit-learn

## Project Description

The model:

* Loads cat and dog images
* Preprocesses the images
* Converts images into grayscale
* Resizes images for training
* Trains an SVM classifier
* Predicts image categories
* Displays model accuracy

## Dataset

Cats and Dogs image dataset from Kaggle.

## Output

The model successfully classifies cat and dog images with good accuracy.
